# 🎀 Hello Kitty 桌面互动宠物

这是一个基于 Python + PyQt5 制作的桌面互动小挂件。Hello Kitty 可以在你的桌面上自由漫步、卖萌，但如果你频繁招惹狂戳她，她会毫不留情地转过头来**比中指**发脾气！

---

## 🎮 玩法与交互指南

1. **拖拽移动**：
   - 鼠标左键按住 Kitty 任意拖动，她会呈现“被拎起后颈皮”四肢扑腾的慌乱状态；
   - 松开鼠标后在当前位置着陆。

2. **单击互动（卖萌）**：
   - 鼠标左键轻点一下：Kitty 歪头害羞、头顶冒粉红小心心，说出软萌语录（如“喵呜~ 摸摸头！”）。

3. **狂戳彩蛋（暴躁中指）**：
   - **连续快速点击 4 次**：Kitty 会忍无可忍，突然转头正对屏幕，抬起白白的小爪子**直挺挺比出中指**，额头蹦出暴躁十字筋（💢），并伴随毒舌气泡（如“🖕 别戳了！没完了是吧？！”、“🖕 素质不详，遇强则强！”）。
   - **摸鱼偶发**：在桌面自由溜达时，也有极小概率突然停下转头向你比个中指再若无其事走开。

4. **右键功能菜单**：
   - 鼠标右键点击 Kitty，可以弹出菜单：
     - **🎀 切换动作**：可直接强制观看【待机】、【溜达】、【卖萌】或【🖕 竖中指】。
     - **🚶 自动漫步**：随时开启/关闭自由走动。
     - **📌 窗口置顶**：勾选后永远悬浮在其他窗口上方；取消勾选则可以放在底层做桌面壁纸挂件。
     - **🔍 调整大小**：支持 80%、100%、125%、150%、200% 任意尺寸缩放。
     - **❌ 退出桌宠**。

5. **系统托盘图标**：
   - 任务栏右下角托盘区常驻 Kitty 小图标，右键可复位显示或安全退出。

## 🚀 启动与分发指南

### 1. Windows 用户（你用）
- **直接双击运行**：工作区根目录下已为你生成好 **[`HelloKitty桌宠.exe`](file:///c:/Users/54185/Desktop/kt/HelloKitty桌宠.exe)**，带 Hello Kitty 专属图标，**无需配置任何 Python 环境**，直接双击就能在桌面上召唤她！
- **发给其他 Windows 朋友**：直接把 `HelloKitty桌宠.exe` 单个文件发给他们即可。

---

### 2. Mac 用户（发给你女朋友）
由于 Windows 系统和 Mac 系统的底层架构（EXE vs APP）不同，Windows 无法直接跨平台生成 Mac 的 Mach-O 二进制文件。你可以通过以下任一方式发给她：

#### 方案 A（最简单：发代码压缩包）
1. 将当前项目文件夹压缩成 `zip` 包（微信/网盘发给她）；
2. 她在 Mac 上解压后，**直接双击里面的 `run_mac.command`**；
   - 脚本会自动检测并在 10 秒内完成环境准备，直接在 Mac 桌面上启动 Hello Kitty！

#### 方案 B（在 Mac 上一键打包为原生 `.app`）
如果她或你在 Mac 电脑上，进入文件夹运行：
```bash
bash build_mac_app.sh
```
即可在 `dist/` 目录下生成一个**原生的苹果应用程序 `HelloKittyPet.app`**，像普通 Mac 软件一样直接拖入应用程序文件夹（Applications）。

#### 方案 C（GitHub 云端免费打包）
将本仓库推送到 GitHub，仓库内置的 `.github/workflows/build.yml` 会自动在云端 Mac 服务器上编译出原生的 `HelloKittyPet-macOS.zip` 供直接下载。

## 🎨 换肤与自定义素材

所有动作的透明 PNG 序列帧均存放在 `assets/` 目录下：
- `assets/idle/`：待机呼吸动作
- `assets/walk/`：漫步动作
- `assets/cute/`：卖萌动作
- `assets/middle_finger/`：比中指反差动作
- `assets/drag/`：被抓起动作

如果你有喜欢的二次元 GIF、动图或像素图，只需拆解为带 Alpha 透明通道的 PNG 替换对应文件夹中的图片（尺寸建议保持正方形，如 128x128 像素）即可无缝换皮！
